# Подключение Instagram

Три способа — от самого полного к самому простому:

| Способ | Что нужно | Что робот получает сам |
|---|---|---|
| **Официальный API** | аккаунт Facebook и приложение Meta (шаги 1–6 ниже) | свои Reels со skip rate, сохранениями, демографией и комментариями; Reels любых бизнес- и авторских аккаунтов |
| **Apify** (без Facebook) | аккаунт [apify.com](https://apify.com) и его токен | публичные Reels ваши и любых открытых аккаунтов: просмотры, лайки, комментарии, видео; поиск аккаунтов в Instagram |
| **Файлы** | ваши видео и таблица со статистикой | только то, что вы загрузили |

Skip rate, сохранения и демография видны только владельцу аккаунта: без официального API их можно добавить таблицей (раздел «Своя статистика таблицей»).

Токены никому не пересылайте и не вставляйте в чат — только в настройки (раздел «Куда положить токен»).

## Apify: без Facebook

[Apify](https://apify.com) — платформа готовых парсеров. Робот запускает их через API: `apify/instagram-reel-scraper` (Reels и цифры), `apify/instagram-profile-scraper` (профиль), `apify/instagram-comment-scraper` (комментарии), `apify/instagram-scraper` (поиск аккаунтов). Оплата — за полученные результаты; на старте у Apify есть бесплатный ежемесячный лимит, точные цены — на странице каждого парсера. Результаты кэшируются на 12 часов (`APIFY_CACHE_HOURS`), повторные запросы не оплачиваются.

1. Зарегистрируйтесь на [apify.com](https://apify.com) (почта или Google).
2. **Apify Console → Settings → API & Integrations** → скопируйте Personal API token.
3. Положите его в `APIFY_TOKEN`, а свой ник Instagram без @ — в `IG_USERNAME` (раздел «Куда положить токен»). Для облачной сессии разрешите домены `api.apify.com`, `*.cdninstagram.com`, `*.fbcdn.net`.
4. Проверка: `hookbot ig-check` — токен, ваш профиль, Reels с просмотрами, скачивание видео, комментарии.

Честно о рисках: сбор данных без разрешения Instagram нарушает его правила использования. Ваш аккаунт при этом не используется и не входит в Instagram, парсеры берут только открытые данные; ответственность за способ сбора лежит на сервисе. Закрытые аккаунты недоступны.

## Своя статистика таблицей

1. **Цифры.** В приложении у каждого ролика «Посмотреть статистику»: просмотры, процент пропусков (skip rate), сохранения, репосты. Перенесите их в таблицу по шаблону [`templates/my_reels.csv`](templates/my_reels.csv). Ролики узнаются по ссылке или коду из ссылки (`/reel/<код>/`). Пробелы в числах, проценты и десятичная запятая понимаются.
2. **С Apify или API:** `hookbot audit --csv my_reels.csv` — таблица дополнит найденные ролики skip rate и сохранениями, и в аудите появится анализ удержания 3 с.
3. **Без подключения вообще:** нужны и видео. Instagram → Центр аккаунтов → «Ваша информация и разрешения» → «Скачать информацию» — придёт архив с роликами (или возьмите исходники из галереи). Колонка «Файл» — имя видеофайла; запуск `hookbot audit --csv my_reels.csv --videos ./reels`. Залетевшие ролики других авторов тогда разбираются по одному: `hookbot ref видео.mp4 --views 250000 --typical 40000`.

Демографию можно переписать из «Профессиональной панели» в описание аудитории: `hookbot profile --audience "…"`.

# Официальный API Instagram

Токен выпускает приложение Meta, а кабинет разработчика открывается только с аккаунтом Facebook ([Meta: Register as a Meta Developer](https://developers.facebook.com/docs/development/register/)). Результат — один токен `IG_ACCESS_TOKEN`; ID аккаунта робот найдёт по нему сам.

## 1. Профессиональный аккаунт и страница Facebook

- Instagram → Настройки → **Тип аккаунта и инструменты** → переключиться на профессиональный аккаунт (автор или бизнес).
- Привяжите аккаунт к странице Facebook (если страницы нет — создайте, хватит пустой): в Instagram «Редактировать профиль» → «Страница» или в Meta Business Suite → Настройки → Аккаунты Instagram.

## 2. Приложение Meta

1. Зайдите на [developers.facebook.com](https://developers.facebook.com/) тем аккаунтом Facebook, который управляет страницей → **Мои приложения** → **Создать приложение**.
2. Выберите сценарий для Instagram **с входом через Facebook** (в панели приложения появятся продукты *Facebook Login for Business* и *Instagram API setup with Facebook login*). Если мастер спрашивает тип приложения — «Бизнес». Meta иногда переименовывает пункты мастера; ориентир — «Instagram API with Facebook Login».
3. Публиковать приложение и проходить проверку Meta не нужно: в режиме разработки оно работает с аккаунтами людей, у которых есть роль в приложении, то есть с вашим.

## 3. Токен в Graph API Explorer

1. Откройте [Graph API Explorer](https://developers.facebook.com/tools/explorer/), справа выберите своё приложение и **User Token**.
2. В **Permissions** добавьте:
   - `instagram_basic` — профиль, свои Reels, поиск авторов;
   - `instagram_manage_insights` — skip rate и демография;
   - `instagram_manage_comments` — комментарии для профиля аудитории;
   - `pages_show_list` — чтобы найти ваш Instagram по токену;
   - `pages_read_engagement` — доступ к Instagram через страницу;
   - `ads_read` — только если страница принадлежит бизнес-портфолио (Business Manager).
3. **Generate Access Token** → в окне входа отметьте свою страницу и аккаунт Instagram → разрешите.
4. Проверка прямо в Explorer: запрос `me/accounts?fields=instagram_business_account{username}` должен вернуть ваш Instagram.

## 4. Долгий токен (60 дней)

Токен из Explorer живёт около часа. Откройте [Access Token Debugger](https://developers.facebook.com/tools/debug/accesstoken/), вставьте токен → **Debug** → внизу **Extend Access Token** → скопируйте новый токен.

## 5. Куда положить токен

Этот раздел общий для API и Apify.

**Облачная сессия Claude Code** (робот запускается здесь):
- меню облачного окружения в заголовке сессии → **Edit** → **Network secrets**: `IG_ACCESS_TOKEN` (API) или `APIFY_TOKEN` (Apify); `ANTHROPIC_API_KEY` — чтобы робот работал сам, без участия сессии;
- там же **Network access → Allowed domains**: `graph.facebook.com` (API) или `api.apify.com` (Apify), и в обоих случаях `*.cdninstagram.com`, `*.fbcdn.net` — для видео (галочку менеджеров пакетов оставьте);
- изменения подхватывает новая сессия; ник Instagram для Apify можно просто написать в чат.

**Telegram-бот на сервере:** в `.env` — `IG_ACCESS_TOKEN=…` или `APIFY_TOKEN=…` и `IG_USERNAME=…`, перезапуск `docker compose up -d`.

**Плагин для Claude:** в настройках плагина hook-master — `ig_access_token`, или `apify_token` и `ig_username`.

`IG_USER_ID` нужен, только если к токену API привязано несколько аккаунтов Instagram — робот назовёт их. Если заданы оба токена, используется официальный API.

## 6. Проверка

```bash
hookbot ig-check
```

Робот по очереди проверяет всё, на что опирается, и для каждой проблемы пишет, что исправить:

| Шаг | Если ❌ или ⚠️ |
|---|---|
| Токен | недействителен или истекает — шаги 3–4 |
| Разрешения | не хватает разрешения — выпустить токен заново с ним |
| Аккаунт Instagram | аккаунт не профессиональный, не привязан к странице или страница не отмечена при выпуске токена |
| Свои Reels, skip rate | skip rate Meta помечает как оценочную метрику в разработке; без неё аудит идёт по просмотрам |
| Комментарии, демография | демография — от 100 подписчиков; без неё профиль аудитории строится по комментариям и хукам |
| Поиск авторов | без Business Discovery нельзя изучить авторов вашей аудитории |

В плагине то же делает инструмент `instagram_check`, его вызывает навык `/hook-master:hook-audit`.

Когда всё ✅:

```bash
pytest -m live          # живые тесты: Claude и Instagram отвечают по-настоящему
hookbot audit           # аудит канала
hookbot target          # целевая аудитория и её авторы
hookbot gap             # что у них залетает и чем отличаются ваши хуки
```

## Продление

Долгий токен живёт 60 дней, доступ к данным — до 90 дней с последнего входа. Робот раз в день проверяет срок и за 7 дней пишет администратору в Telegram. Пока токен не истёк — нажмите **Extend Access Token** (шаг 4) и обновите `IG_ACCESS_TOKEN`; если истёк — повторите шаги 3–4.
