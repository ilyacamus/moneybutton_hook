# Робот на своём компьютере (режим A)

Автономный обучающийся разведчик работает на вашем Mac: сам собирает Reels авторов ниши с домашнего интернета, разбирает первые 3 секунды и учится, что отличает залетевшие ролики от обычных у тех же авторов. Сторонние сервисы сбора не нужны: только Instagram, ffmpeg, Whisper и Claude.

Режим B — тот же код на сервере: переменная `IG_WEB_PROXY` с адресом «домашнего» (резидентного) прокси, потому что Instagram блокирует анонимные запросы с серверных IP.

## Что делает робот в каждом цикле

1. **Сбор.** Читает публичные профили авторов из списка наблюдения — по одному запросу на автора, с паузой около 20 с. Новые ролики, просмотры и лайки сохраняются в базу; история копится от цикла к циклу.
2. **Рост ниши.** Робот смотрит «похожие аккаунты», которые Instagram показывает рядом с авторами. Если в описании профиля или в подписях нового автора есть слова его ниши из [справочника ниш](NICHES.md), робот добавляет автора в наблюдение под той же нишей. Свой список слов можно задать в `NICHE_KEYWORDS`. Каждого кандидата робот проверяет один раз.
3. **Разметка.** Ролик старше 72 часов сравнивается с медианой других роликов того же автора: залетевший — от 3×, обычный — 0,67–1,5×.
4. **Разбор вслепую.** Для залетевших роликов и парных обычных того же автора: кадры 0–3 с, звук и склейки (ffmpeg), речь первых секунд (Whisper), оценка хука Claude без знания просмотров. Дневной лимит разборов — `SCOUT_DAILY_BUDGET`.
5. **Обучение.** Что отличает залетевшие ролики от обычных:
   - признаки, приёмы и критерии с поправкой на множественные проверки;
   - сверка с исследованиями;
   - тренды по 30-дневным окнам;
   - обновление весов оценщика;
   - переобучение модели залёта каждой ниши ([NICHES.md](NICHES.md)).
6. **Отчёт.** Новые авторы, сдвиги трендов, расхождения с наукой.

Instagram ограничивает слишком частые запросы. Робот это распознаёт: делает паузу на 30 минут и продолжает в следующем цикле. Аккаунт в Instagram не используется и не входит в систему.

## Установка (15 минут)

```bash
# 1. Инструменты (Homebrew: https://brew.sh)
brew install python@3.13 ffmpeg git

# 2. Код
git clone -b claude/pensive-carson-8axwn7 https://github.com/ilyacamus/moneybutton_hook.git
cd moneybutton_hook
python3.13 -m venv .venv
.venv/bin/pip install -e ".[asr]"

# 3. Настройки
cp .env.example .env
```

В `.env` заполните:

```
ANTHROPIC_API_KEY=...        # console.anthropic.com → API keys: разбор хуков
IG_SOURCE=web                # свой сборщик
SCOUT_ASR=1                  # речь первых секунд через Whisper (модель скачается один раз)
SCOUT_DAILY_BUDGET=60        # сколько роликов разбирать в день (каждый — запрос к Claude)
SCOUT_INTERVAL_MINUTES=180   # как часто запускать цикл
SCOUT_COLLECT_PER_CYCLE=60   # сколько авторов читать за цикл (по кругу)
HOOKBOT_DB=data/hookbot.db
```

## Первый запуск

```bash
set -a; . ./.env; set +a
.venv/bin/hookbot ig-check --username kirillmedved77      # доступ к Instagram с этого компьютера
.venv/bin/hookbot scout seed niche_creators.txt --niche "Крипта и трейдинг"
.venv/bin/hookbot niche import-pack crypto.json          # если есть пакет ниши (хранится приватно)
.venv/bin/hookbot scout once                              # один цикл: сбор → разбор → выводы
.venv/bin/hookbot science --niche крипто-трейдинг         # что уже выяснено
```

`niche_creators.txt` — стартовый список авторов ниши (364 аккаунта, найдены по залетевшим роликам). Дальше робот расширяет его сам.

## Автономная работа

Постоянно, пока Mac включён:

```bash
.venv/bin/hookbot scout run
```

Автозапуск при входе в систему:

```bash
sed "s#REPO#$PWD#" scripts/macos/com.moneybutton.scout.plist > ~/Library/LaunchAgents/com.moneybutton.scout.plist
launchctl load ~/Library/LaunchAgents/com.moneybutton.scout.plist
tail -f data/logs/scout.log
```

Остановить: `launchctl unload ~/Library/LaunchAgents/com.moneybutton.scout.plist`.

## Что смотреть

| Команда | Что показывает |
|---|---|
| `hookbot science --niche крипто-трейдинг` | что отличает залетевшие ролики, сверка с наукой, тренды |
| `hookbot scout list` | кто в наблюдении, включая найденных роботом |
| `hookbot validate` | насколько можно доверять оценщику |
| `hookbot score "текст хука"` | оценка нового хука с учётом выученного |
| `hookbot generate сценарий.txt` | хуки под сценарий с учётом выученного |

## Стоимость

- Сбор — бесплатно.
- Разбор — один запрос к Claude на ролик: 6 кадров и текст. Расход виден в консоли Anthropic. Лимит в день задаёт `SCOUT_DAILY_BUDGET`.
- Whisper работает на компьютере бесплатно.

## Ограничения

- Публичный профиль показывает около 12 последних публикаций. Полная история автора накапливается за счёт ежедневного сбора, поэтому первые выводы — через несколько дней работы.
- Instagram меняет внутренние форматы. Если `ig-check` перестал видеть просмотры или видео, сборщик нужно обновить.
- Сбор без разрешения Instagram нарушает его правила. Читаются только открытые аккаунты, вход в аккаунт не выполняется.
