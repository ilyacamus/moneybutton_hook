# Как продавать

Один движок — два продукта:

| | Telegram-бот | Плагин для Claude |
|---|---|---|
| Кому | Авторам и SMM-специалистам, которые живут в телефоне | Продюсерам, агентствам, авторам, которые работают в Claude Code / Cowork |
| Кто платит за ИИ | Вы (Claude API) | Покупатель (его подписка Claude) |
| Модель оплаты | Пакеты анализов за Telegram Stars | Доступ к приватному маркетплейсу |
| Самообучение | На сервере, по каждому пользователю + общая модель (opt-in) | Локально у покупателя (`${CLAUDE_PLUGIN_DATA}/hooks.db`) |

## Telegram-бот

### Оплата

Цифровые товары в Telegram-ботах продаются за **Telegram Stars** (валюта `XTR`) — это уже реализовано: пакеты, счёт, pre-checkout-проверка, идемпотентное зачисление, `/paysupport`, `/terms`, возврат админом через `/refund <charge_id>`. Платёжный провайдер подключать не нужно.

Пакеты задаются переменной `HOOKBOT_PACKS` (`id:анализы:звёзды`). По умолчанию:

| Пакет | Анализов | Цена | ⭐ за анализ |
|---|---|---|---|
| start | 15 | 200 ⭐ | 13.3 |
| pro | 50 | 600 ⭐ | 12 |
| studio | 150 | 1500 ⭐ | 10 |

Стоимость операций: оценка, генерация, переписывание, подбор действий — 1 анализ; разбор видео — 2. Внесение статистики бесплатно и даёт +1 анализ (только за хуки, которые пользователь сам оценил, — так бонус нельзя накрутить генерацией).

### Себестоимость

Оценка на модели `claude-opus-5-5` при `effort=medium` (цены: $4 / $20 за 1M токенов, чтение кэша $0.20):

| Часть запроса | Токены | Стоимость |
|---|---|---|
| Системный промпт с базой знаний (кэширован) | ~11 тыс. | ~$0.002 |
| Контекст самообучения + задача + ввод | 1.5–3 тыс. | $0.006–0.012 |
| Ответ (рассуждение + JSON) | 2.5–5 тыс. | $0.05–0.10 |
| Кадры видео (6 шт.) | ~4 тыс. | ~$0.017 |

Ориентир — **$0.06–0.12 за анализ**. Если кэш остыл (нет запросов 5 минут), первая запись кэша добавляет ~$0.05. Реальный расход пишется в лог движка (`claude Evaluation stop=… in=… cache_read=… out=…`) — посчитайте среднее по первым сотням запросов, прежде чем фиксировать цены.

Telegram выплачивает разработчикам порядка $0.013 за звезду (проверьте актуальный курс вывода). При 12 ⭐ за анализ это ~$0.16 выручки против ~$0.10 себестоимости. Рычаги маржи:

- **Модель.** `HOOKBOT_MODEL=claude-sonnet-5-5` примерно вдвое дешевле ($2 / $10). Это ваш выбор качества против цены: прогоните одинаковые хуки через обе модели, прежде чем переключать.
- **Effort.** `HOOKBOT_EFFORT=low` сокращает рассуждение; `high` — для премиум-тарифа.
- **Бесплатные анализы.** `FREE_CREDITS` (по умолчанию 5) — ваша стоимость привлечения: ~$0.5 на пользователя.

### Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather), получите токен.
2. Заполните `.env` по образцу `.env.example` (`TELEGRAM_BOT_TOKEN`, `ANTHROPIC_API_KEY`, `ADMIN_IDS`, `SUPPORT_CONTACT`).
3. `docker compose up -d --build`.
4. Проверьте покупку на себе, затем верните звёзды: `/refund <charge_id>` (id — в логе бота).
5. `/admin` — пользователи, активные за 7 дней, операции, выручка в звёздах, внесённые результаты.

### Рост

- **Результаты = удержание пользователя.** Бот сам напоминает внести статистику через 48 часов; чем больше данных, тем точнее прогноз — у пользователя появляется причина оставаться.
- **Общая модель.** Пользователи с `/share on` улучшают стартовую калибровку для новичков — это ваш накапливаемый актив, которого нет у конкурентов с «голым» промптом.
- **Плейбук.** Персональные правила «что работает у вашей аудитории» — то, за что платят агентства. Хорошая база для тарифа «для агентств» с несколькими аккаунтами.

## Плагин для Claude

Плагин работает на подписке Claude покупателя, поэтому себестоимость продажи для вас — ноль.

Установка у покупателя (Claude Code 2.1.275+):

```
/plugin install hook-master --marketplace ilyacamus/moneybutton_hook
```

или в два шага:

```
/plugin marketplace add ilyacamus/moneybutton_hook
/plugin install hook-master@moneybutton
```

Варианты распространения:

- **Приватный репозиторий-маркетплейс.** Держите репозиторий приватным и после оплаты (Tribute, Boosty, Gumroad и т. п.) выдавайте покупателю доступ на чтение. Claude Code ставит плагины из приватных репозиториев через git-доступ пользователя. Обновления приходят всем покупателям автоматически.
- **Бесплатный плагин как лид-магнит** для бота: базовые навыки бесплатно, «общая модель» и плейбук на данных тысяч роликов — в боте.

Нужен Python 3.11+ (`python3` в `PATH`) — на нём работает MCP-сервер памяти. Разбор видео дополнительно требует `ffmpeg`.

## Юридическое

- В `/terms` прямо сказано: рекомендации ИИ не гарантируют охваты.
- Данные пользователя используются для его персональной модели; в общую — только по `/share on`; удаление — `/deletedata`.
- Не обещайте в рекламе «вирусность» и конкретные охваты.
