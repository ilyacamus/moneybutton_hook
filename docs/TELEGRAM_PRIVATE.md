# Личный Telegram-бот, который работает сам

Бот отвечает только вам. Он работает круглосуточно без сессии Claude Code и опирается на собранные данные:

- **модели крипто-ниши:** основная, обученная на 1045 залетевших роликах, и модель «автор против себя» на 347 роликах;
- **калибровка удержания** на 72 роликах вашего канала (@kanyuka_moneybutton);
- **база знаний:** триггеры, рубрика и исследования.

Каждый ваш запрос — оценка хука, хуки по сценарию, разбор видео — бот обрабатывает сам через Claude API. Сам бот делает ещё три вещи:

- через 48 часов после оценки просит статистику ролика и учится на ней;
- каждый день сохраняет копию базы;
- переобучает модель ниши, когда появились новые данные.

## Где запускать

| | Mac | Сервер (VPS) |
|---|---|---|
| Работает | пока Mac включён и не спит | круглосуточно |
| Стоимость | бесплатно | ≈ €4–6 в месяц (например, Hetzner CX22, Ubuntu 24.04) |
| Claude API | только если Mac в стране, где [API доступен](https://www.anthropic.com/supported-countries) | сервер берите в поддерживаемой стране (Германия, Финляндия, Нидерланды) |
| Когда выбрать | попробовать сегодня | бот должен работать всегда; потом его откроете для клиентов |

Совет: начните на Mac, а для постоянной работы и будущей продажи перенесите бота на сервер. Это тот же скрипт.

**Один токен — один запущенный бот.** Если бот уже работает на Mac, перед запуском на сервере остановите его на Mac. Иначе Telegram выдаст ошибку `Conflict`.

## Что подготовить (10 минут)

1. **Токен бота.** Напишите [@BotFather](https://t.me/BotFather) команду `/newbot`, задайте имя и ник бота. Токен вида `1234567890:AA…` придёт в ответ. Никому его не пересылайте.
2. **Ваш Telegram id.** Напишите что угодно [@userinfobot](https://t.me/userinfobot), он пришлёт число `Id`.
3. **Ключ Claude API.** [console.anthropic.com](https://console.anthropic.com) → API keys → Create key, затем пополните баланс в Billing. Анализ стоит несколько центов; для старта хватит $10–20.
4. **Доступ к приватному репозиторию данных** `moneybutton_data`. На Mac обычно уже есть. На сервере выполните `gh auth login` или скопируйте базу вручную (см. ниже).

## Установка одной командой

```bash
git clone -b claude/pensive-carson-8axwn7 https://github.com/ilyacamus/moneybutton_hook.git
cd moneybutton_hook
./scripts/setup_bot.sh
```

Скрипт:
1. создаёт окружение Python и ставит зависимости;
2. скачивает базу знаний из `moneybutton_data` (существующую базу не трогает);
3. спрашивает токен, ваш id и ключ Claude, без вывода на экран, и записывает их в `.env` с доступом только для вас;
4. проверяет всё по-настоящему: принимает ли Telegram токен, работает ли ключ Claude из этой страны, видит ли бот ваш канал и модель ниши;
5. ставит бота в автозапуск: launchd на Mac, systemd на сервере. После сбоя или перезагрузки бот поднимется сам.

Повторный запуск безопасен: он обновит зависимости и снова проверит настройки.

**Сервер с нуля (Ubuntu):**

```bash
sudo apt update && sudo apt install -y git ffmpeg python3.12-venv gh
gh auth login            # вход в GitHub для приватных данных
git clone -b claude/pensive-carson-8axwn7 https://github.com/ilyacamus/moneybutton_hook.git
cd moneybutton_hook && ./scripts/setup_bot.sh
```

Без GitHub на сервере скопируйте базу с Mac и запустите скрипт:

```bash
scp ../moneybutton_data/db/hookbot.db user@server:moneybutton_hook/data/
```

## Как пользоваться

Откройте бота в Telegram и нажмите **Start**. В приветствии видны ниша и модель ниши.

| Что прислать | Что получите |
|---|---|
| Фразу из первых 3 секунд (можно добавить строки «Текст на экране:», «Визуал:») | оценку по 9 критериям, прогноз удержания для вашего канала, **потенциал залёта в крипто-нише** и **сравнение с вашим обычным хуком**, 3 улучшенные версии |
| Сценарий (`/generate …` или кнопка) | 8 хуков на разных приёмах |
| Видео | разбор кадров 0–3 с, звука и склеек |
| `/result 80 skip 38% просмотры 12к` | бот учится на реальном результате |
| `/science`, `/stats`, `/playbook` | что работает в нише, чему бот научился, правила для вашего канала |

Хуки из прошлых тестов уже в базе бота: сценарий EasyTrade — #80–88, методичка по риск-менеджменту — #73–79. Результаты по ним вносите прямо в боте.

## Обслуживание

| Задача | Команда |
|---|---|
| Журнал | `tail -f data/logs/bot.log` |
| Остановить (Mac) | `launchctl unload ~/Library/LaunchAgents/com.moneybutton.bot.plist` |
| Остановить (сервер) | `systemctl --user stop moneybutton-bot` |
| Обновить код | `git pull && ./scripts/setup_bot.sh` |
| Резервные копии | `data/backups/hookbot-ГГГГММДД.db`, последние 7 дней (`BACKUP_KEEP`) |

Чтобы бот ещё и сам собирал ролики ниши, добавьте в `.env` `SCOUT_ENABLED=1` и `IG_SOURCE=web` ([LOCAL_MODE.md](LOCAL_MODE.md)). Сбор работает с домашнего интернета. С сервера Instagram без «домашнего» прокси (`IG_WEB_PROXY`) не отвечает.

## Открыть для клиентов и принимать оплату

Оплата уже встроена: пакеты анализов за Telegram Stars, бесплатные анализы на старте, возвраты через `/refund`. Когда будете готовы:

1. В `.env`:
   - поставьте `BOT_PRIVATE=0`;
   - задайте `FREE_CREDITS` и `HOOKBOT_PACKS` (например `start:15:200,pro:50:600`: 15 анализов за 200 ⭐) и `SUPPORT_CONTACT`.
2. Перезапустите бота.
3. Вы останетесь в `ADMIN_IDS`: без лимитов, с `/admin` и `/refund`.

Экономика и цены — в [BUSINESS.md](BUSINESS.md). Оплата картой (ЮKassa, Stripe) подключается отдельно, это следующий шаг.
