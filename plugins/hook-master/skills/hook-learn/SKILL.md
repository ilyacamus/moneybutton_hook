# Обновить плейбук

## Шаги

1. Вызови `training_data` (MCP `hook-memory`): все хуки автора с фактическим удержанием 3 с, калибровка (веса критериев, точность прогноза) и влияние триггеров.
2. Если результатов меньше 3 — скажи, что учиться пока не на чем, и покажи хуки, ждущие статистики (`list_hooks` с `without_results: true`).
3. Найди закономерности, которые отличают сильные хуки от слабых **у этой аудитории**:
   - какие критерии рубрики сильнее связаны с удержанием (смотри `calibration.weights` против стартовых весов в `${CLAUDE_PLUGIN_ROOT}/knowledge/rubric.md`);
   - какие триггеры дают прирост, какие — минус (`trigger_lift`);
   - общие черты топ-3 и антитоп-3: длина фразы, цифры, лицо в кадре, формат, первое слово.
4. Сформулируй по 2–5 правил «делать больше» и «делать меньше». Каждое — с доказательством в цифрах и честной уверенностью: при n < 10 максимум `medium`. Не повторяй общие советы, если данные их не подтверждают.
5. Предложи 2–4 A/B-теста хуков, которые быстрее всего проверят гипотезы.
6. Сохрани через `save_playbook` — плейбук будет подмешиваться во все следующие оценки и генерации.

## Формат ответа

```
📘 Плейбук (<n> роликов, точность прогноза ±<mae> п.п.)
<главный вывод>

✅ Делать больше
- <правило> — <доказательство> (уверенность)
❌ Делать меньше
- …
🧪 Протестировать
- …
```
