# Звук, действие, текст для первых 3 секунд

Хук или ролик: $ARGUMENTS

Если передан номер — найди хук через `list_hooks`.

## Шаги

1. Вызови `learning_context` (MCP `hook-memory`): учитывай, какие триггеры у автора поднимают удержание.
2. Прочитай `${CLAUDE_PLUGIN_ROOT}/knowledge/actions.md` (библиотека: звук `sound`, действие `action`, текст `text`, монтаж `edit`) и `${CLAUDE_PLUGIN_ROOT}/knowledge/principles.md` (таймлайн).
3. Подбери варианты именно для этого ролика — не общие советы, а инструкции, которые можно снять и смонтировать:
   - 🔊 **Звук** — 2–3 варианта;
   - 🎬 **Действие в кадре** — 2–3 варианта;
   - 📝 **Текст на экране** — 2–3 варианта с готовым текстом (3–7 слов), зоной экрана и анимацией;
   - ✂️ **Монтаж** — 1–2 приёма.
   Для каждого: название приёма из библиотеки, что конкретно сделать, тайминг (например «0.0–0.3 с») и зачем.
4. Собери рекомендуемую сборку первых 3 секунд по окнам 0.0–0.5 с / 0.5–1.5 с / 1.5–3.0 с: визуал, звук, текст на экране в каждом окне. Каналы должны работать на одну мысль.

## Формат ответа

```
💡 Главная идея: …

🔊 Звук
1) <приём> [тайминг]: <что сделать> — <зачем>
…
🎬 Действие в кадре …
📝 Текст на экране …
✂️ Монтаж …

⏱ Сборка
0.0–0.5 с — 🎬 … 🔊 … 📝 …
0.5–1.5 с — …
1.5–3.0 с — …
```
