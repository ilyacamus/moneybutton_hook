# Аудит канала

Аргументы: $ARGUMENTS

Цель — выучить, что удерживает первые 3 секунды **у этой аудитории**, а не в среднем по ленте. Разбор слепой: модель не видит просмотров и skip rate ролика, пока ставит оценки, — иначе связь «оценка → удержание» будет подогнана.

## Шаги

1. Вызови `audit_collect` (MCP `hook-memory`):
   - если пользователь дал CSV-выгрузку статистики (Meta Business Suite / «Профессиональная панель») — `csv_path` и `videos_dir` (папка со скачанными роликами; файлы сопоставляются по ID публикации или коду ролика в имени);
   - иначе без аргументов — ролики придут через Instagram API (токен задаётся в настройках плагина `ig_access_token` / `ig_user_id`).
   Если инструмент ответил, что Instagram не подключён и CSV нет, — объясни оба способа и остановись.
2. Разбирай ролики пачками: `next_reels` с `scope: "own"`, `limit: 5`. Для каждого ролика из ответа:
   - открой каждый кадр (Read) по порядку — это 0; 0,5; 1; 1,5; 2 и 3 с;
   - учти `video_facts`: когда начинается звук, сколько склеек в первые 3 с;
   - оцени по `${CLAUDE_PLUGIN_ROOT}/knowledge/rubric.md` (9 критериев, целые 0–10, средний хук ленты — 4–5), отметь триггеры из `${CLAUDE_PLUGIN_ROOT}/knowledge/triggers.md` и анти-паттерны из `${CLAUDE_PLUGIN_ROOT}/knowledge/anti-patterns.md`;
   - `spoken_hook` — только то, что видно или следует из подписи; если речь неизвестна, оставь пусто и `spoken_source: "unknown"`. Ничего не додумывай;
   - честно отметь `face_first_second`, `text_first_second`, `motion_first_second` по кадрам 0–1 с;
   - сохрани через `save_reel_analysis`.
   Повторяй, пока `next_reels` не вернёт пустой список. Если роликов больше 30 — после первых 30 спроси, продолжать ли (каждая пачка — это время и токены).
3. Вызови `audit_report`.
4. Если пользователь просит и дальше — предложи `/hook-master:hook-target`: найти авторов с той же аудиторией и сравнить с их залетевшими роликами.

## Как читать отчёт

- `hold_effects` — связь признака хука с удержанием 3 с (ρ Спирмена, перестановочный тест, поправка Бенджамини–Хохберга). Вердикт «подтверждено» — q < 0,10; «тенденция» — q < 0,25. Остальное не показывай как вывод.
- `reach_effects` — то же для охвата относительно медианы канала.
- `science` — сверка с литературой: «доказано: наука + данные» сильнее, чем просто корреляция в канале.
- При `n_with_skip_rate` < `min_reels` выводов по удержанию нет — так и скажи и посоветуй догрузить ролики.

## Формат ответа

```
🔎 Аудит канала: <n_reels> роликов, разобрано <n_studied>, со skip rate <n_with_skip_rate>
Медиана: <median_views> просмотров, skip rate <median_skip_rate>%

✅ Что удерживает вашу аудиторию
- <признак>: ρ=<rho>, q=<q> — <что это значит простыми словами> <наука: статус>
❌ Что теряет её
- …
🚀 Прорывные ролики: <хуки breakouts и чем отличаются>
🏆 Лучшее удержание / 🛑 худшее: <хуки>

Что делать в следующих 5 роликах:
1. …
```

Не обещай больше, чем дают данные: при 10–20 роликах выводы — гипотезы для A/B, а не законы. Свои ролики со skip rate уже стали обучающими данными — следующие оценки (`/hook-master:hook-score`) откалиброваны на них.
